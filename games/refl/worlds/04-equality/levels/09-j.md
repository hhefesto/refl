You have now matched on `refl` in many different ways. Time to state in one line what all of them have in common.
That's **J**, and it looks hard only because of how much it says:

```agda
J : (P : ∀ y → x ≡ y → Set) → P x refl → ∀ {y} (p : x ≡ y) → P y p
```

Compare it with `subst`, from the last level. `subst` carries a motive `P` across an equation. So does J. The
difference is that J's motive can also mention the *proof of the equation itself*, which is why `P` takes two
arguments: an endpoint `y`, and a proof `x ≡ y`.

In words: suppose you want to prove something about every `y` and every proof `p : x ≡ y`. It's enough to prove it
in the one case where `y` is `x` and `p` is `refl`. Everything else follows.

Why? Because `refl` is the only constructor. The proof is what you'd hope: **Case split** on `p`. Ask for the
**Goal** before and after, and watch how much it changes.

<!-- @conclusion -->
`sym`, `trans`, `cong` and `subst` are all instances of J, each with its own motive. And the `--without-K` flag on
every level restricts *how* this matching may happen: `refl` can only be matched when one endpoint is a variable
that can be replaced. That restriction keeps the game compatible with homotopy type theory, and it's what makes the
last theorem of this world interesting.
