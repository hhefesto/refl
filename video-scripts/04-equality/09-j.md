# Equality 9: Pattern matching on refl is J

About 1 min 00 s. Agda.

Statement: `J : ∀ {A : Set} {x : A} (P : ∀ y → x ≡ y → Set) → P x refl → ∀ {y} (p : x ≡ y) → P y p`

**Open.** We've matched on `refl` in a lot of ways by now. Here's the one principle behind every one of those matches, and it's called J.

1. **Do:** Read the statement slowly.
   **Say:** To prove something about every proof of `x ≡ y`, it's enough to prove it for `refl`.

2. **Do:** Press Goal and read the type before splitting.
   **Say:** The goal is `P y p`. Watch what happens to it.

3. **Do:** Case split on `p`, then give `d`.
   **Say:** Matching on `refl` makes `y` be `x`. Now the goal is `P x refl`, which is exactly `d`.

**Close.** That's J. `sym`, `trans`, `cong` and `subst` are all instances of it.

**Finished proof:**

```agda
J P d refl = d
```
